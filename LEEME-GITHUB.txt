PÁGINA EN GITHUB (con icono y sin el aviso de Apps Script)

IDEA: la web (pantalla) vive en GitHub Pages; Google Apps Script solo guarda los datos
en la hoja. Así el móvil muestra tu icono, el nombre "Mariano" y no sale el aviso de Google.

PARTE 1 - Apps Script (solo cambia Code.gs)
1. Abre tu proyecto de Apps Script. En Code.gs borra todo y pega el Code.gs nuevo. Guarda.
2. Implementar > Administrar implementaciones > lápiz > Versión: "Nueva versión" > Implementar.
3. Copia la URL de la aplicación web (termina en /exec).
   (El archivo "index" de Apps Script ya no hace falta.)

PARTE 2 - Poner la URL en la web
1. Abre index.html con un editor de texto (Bloc de notas).
2. Busca:  var API_URL = 'PEGA_AQUI_LA_URL_DE_APPS_SCRIPT';
   y cambia el texto entre comillas por tu URL /exec. Guarda.
   (En este paquete ya está puesta tu URL, no hace falta tocar nada.)

PARTE 3 - GitHub
1. Crea cuenta en github.com (gratis) si no tienes.
2. Arriba a la derecha: "+" > New repository. Nombre: mariano. Marca "Public". Create repository.
3. Pulsa "uploading an existing file", arrastra TODOS los archivos de esta carpeta
   (index.html, manifest.webmanifest, sw.js y los 5 .png) y pulsa "Commit changes".
4. Settings > Pages. En "Branch" elige main y carpeta / (root). Save.
5. Espera 1-2 minutos. La web estará en:  https://TU-USUARIO.github.io/mariano/

PARTE 4 - Móvil
Borra el acceso directo antiguo. Abre la nueva dirección y "Añadir a pantalla de inicio".
Saldrá la gota verde y el nombre Mariano.

NOTAS
- El repositorio es público: se ve el código y la URL de Apps Script. Los datos siguen
  protegidos solo por no compartir la dirección (igual que antes).
- Para cambiar la web en el futuro: en GitHub, abre index.html > lápiz > pega el nuevo > Commit.
  Si no ves el cambio, cierra y abre la web (o recarga con fuerza).
